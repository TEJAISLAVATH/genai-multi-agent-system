# 🤖 Multi-Agent AI System

This project demonstrates a simple Multi-Agent AI system built using Python and Ollama.

## Features

- Planner Agent (breaks task into steps)
- Writer Agent (generates answer)
- Critic Agent (improves answer)
- Local LLM using TinyLlama

## Tech Stack

- Python
- Ollama
- TinyLlama

## How to Run

1. Install Ollama
2. Pull model:
   ollama pull tinyllama

3. Run:
   python app.py

## Example

Input:
Explain Artificial Intelligence in simple words

Output:
Step-by-step AI generated response using multiple agents.
